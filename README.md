
# Python Data Analysis Projects

This repository contains collection of Python data analysis projects using Pandas, NumPy, and Matplotlib with EDA and data visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Projects

### 1. Weather Data Analysis

Features:
- Data Cleaning
- Monthly Analysis
- Seasonal Analysis
- Statistical Analysis
- Line Plot
- Bar Plot
- Histogram
- Extreme Weather Detection

### 2. Movie Ratings Analysis

Features:
- Data Cleaning
- Rating Statistics
- Genre Analysis
- Director Analysis
- Year-wise Analysis
- Scatter Plot
- Line Plot
- Horizontal Bar Plot

## Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- NumPy Calculations
- Pandas GroupBy
